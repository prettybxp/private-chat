# 私人聊天室

本机部署的单房间 Web 聊天室：访客昵称 + Cookie 记住身份，WebSocket 实时文字，内存保留最近 100 条消息。

## 功能

- 进房填写昵称，刷新后 Cookie 自动恢复身份
- 固定单房间，仅文字消息
- 最近 100 条聊天记录（进程内存，重启清空）
- 左侧聊天、右侧在线成员（关页/断线即离线）
- 默认端口 **8088**

## 环境要求

- **Node.js 18+**（推荐 20+）。若 `npm start` 报 `Unexpected token '?'`，说明 Node 过旧，请先升级。

## 安装与运行

```bash
cd /home/chat
npm install
```

### 生产模式（推荐本机使用）

```bash
npm run build
npm start
```

浏览器访问：<http://127.0.0.1:8088>  
局域网：<http://你的本机IP:8088>

### 开发模式

前后端分离：Vite 前端 `5173`，WebSocket 服务 `8088`。

```bash
npm run dev
```

浏览器访问：<http://127.0.0.1:5173>

## 配置

| 变量 | 说明 | 默认 |
|------|------|------|
| `PORT` | HTTP + WebSocket 端口 | `8088` |
| `HOST` | 监听地址（`0.0.0.0` 允许局域网访问） | `0.0.0.0` |
| `NODE_ENV` | `production` 时托管静态页面 | 仅 `npm start` 设置 |

若外网仍无法访问，请检查本机防火墙是否放行 `8088` 端口。

## 限制说明

- 聊天记录仅存于内存，**服务重启后全部丢失**
- 每房间最多保留 100 条历史
- 每人每秒最多发送 5 条消息
- 无 HTTPS、无登录，适合本机/局域网私人使用
